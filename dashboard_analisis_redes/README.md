# SocialPulse — Dashboard de análisis de redes sociales

Dashboard web estático para representar el análisis de una cuenta ficticia de redes sociales.

## Contenido
- `index.html`: estructura principal del dashboard.
- `styles.css`: estilos y diseño adaptable a escritorio, tablet y móvil.
- `app.js`: 20 registros ficticios diarios, filtro de fechas y renderizado de métricas, tabla y gráfico.

## Cómo ejecutar
1. Descomprime el archivo ZIP.
2. Abre la carpeta `dashboard_analisis_redes`.
3. Ejecuta `index.html` con doble clic o ábrelo desde Visual Studio Code con Live Server.

No requiere instalación de dependencias ni base de datos.

## Secciones incluidas
- Alcance total.
- Interacciones y distribución por tipo.
- Seguidores y crecimiento de comunidad.
- Publicaciones destacadas.
- Filtro por rango de fechas entre el 11 y el 30 de octubre de 2026; actualiza las métricas, el gráfico y el detalle diario.

## Nota
Todos los datos, publicaciones y métricas son ficticios y se usan únicamente para demostrar la interfaz. El dashboard no está conectado a Instagram, Facebook ni a otra plataforma real.
